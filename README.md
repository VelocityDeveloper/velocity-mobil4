Velocity Child Mobil 4
======================

Child theme for the Velocity System WordPress theme.

Current version: **2.0.0**

### Usage
Download the release ZIP and upload it from **Appearance > Themes > Add New > Upload Theme**, or extract it to `wp-content/themes/velocity-mobil4/`.
